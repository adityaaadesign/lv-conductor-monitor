# Archive

`frontend-phase2/` is the earlier five-page dashboard (Overview, Topology, Event history,
Trends & diagnostics, Simulation). It was replaced by the single simple page in
`frontend/` because it was too complicated for the project scope.

It is kept only for reference. It is **not served** by the application and is not kept
up to date (it also needed the Chart.js package, which has been removed).
